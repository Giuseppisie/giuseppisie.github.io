16-bit MIPS-like CPU — Logisim

Project overview

Role: Designer & implementer · Tools: Logisim, assembler, testbench · Year: 2024

This project implements a 16-bit, word-addressed, MIPS-like RISC CPU in Logisim. The design is a single-cycle CPU intended as an educational reference: it demonstrates a clear datapath, an ALU with common ops, a small register file, separate instruction ROM and data RAM, PC and branch/jump logic, and simple I/O (TTY/keyboard). It is not pipelined — the emphasis is teaching fundamentals and correctness.

The implementation includes an assembler / testbench (used to generate ROM images), a memory write latch (to match Logisim RAM timing), and a small set of MIPS-inspired instructions (R/I/J forms, load/store, branches, jal/jr).
